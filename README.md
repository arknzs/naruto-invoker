# Gesture Invoker

Программа с графическим интерфейсом для Windows: распознаёт жесты рук с веб-камеры и эмулирует нажатия клавиш по заданной последовательности.

## Возможности

- Выбор камеры прямо в интерфейсе (список, обновление, старт/стоп).
- Отображение точек захвата (скелет кисти) поверх видео; отключается галочкой.
- Жесты для одной и двух рук: 13 встроенных для одной руки и 10 для двух.
- Запись собственных жестов (одна или две руки) с привязкой названия.
- Бинд жеста на последовательность клавиш с настраиваемыми интервалом и удержанием.
- Настоящая эмуляция нажатий через `SendInput` со сканкодами (а не хоткеи), поэтому работает и в играх.
- Конфигурация сохраняется в `gestures.json`.

## Установка и запуск

Требуется Windows и Python 3.8–3.11 (под `mediapipe==0.10.14`).

```
pip install -r requirements.txt
python app.py
```

Зависимости: `opencv-python`, `mediapipe`, `numpy`, `Pillow`.

## Использование

1. Выберите камеру в списке и нажмите «Старт».
2. Включите галочку «ЭМУЛЯЦИЯ КЛАВИШ ВКЛЮЧЕНА» (по умолчанию выключена).
3. Двойной клик по жесту в списке (или «Бинд...») открывает настройку бинда.
4. «Тест» нажимает клавиши через 2 секунды, чтобы вы успели переключиться в нужное окно.

### Формат последовательности клавиш

Токены через пробел, нажимаются по порядку:

| Запись | Значение |
|---|---|
| `q w a s d` | поочерёдные нажатия |
| `ctrl+c` | комбинация (клавиши зажимаются вместе) |
| `wait:500` | пауза 500 мс |
| `space enter tab esc up down left right f1..f12 shift ctrl alt win` | специальные клавиши |

Параметры бинда:
- **Интервал** — пауза между нажатиями, мс.
- **Удержание** — сколько мс держится каждая клавиша.
- **Повторять** — повторять последовательность, пока жест удерживается.
- **Псевдослучайный разброс интервалов** — каждая пауза получает случайное отклонение, плюс-минус указанный процент. Например, при интервале 100 мс и разбросе 15% задержки будут около 95, 107, 88, 112 мс. Разброс удержания клавиши настраивается отдельно. В списке жестов такие бинды помечены значком `~`.

### Свои жесты

«Новый жест...» → название, одна или две руки → «Записать» (через 3 секунды снимается шаблон по 10 кадрам) → «Сохранить». Сразу откроется окно бинда. Пользовательские жесты помечены `*`.

## Настройки распознавания

- **Допуск шаблона** — строгость сравнения записанных жестов (меньше = строже).
- **Удержание жеста (кадров)** — сколько кадров подряд жест должен держаться до срабатывания.

Встроенные жесты определяются по тому, какие пальцы подняты; записанные — по сравнению формы кисти с шаблоном.

## Примечания

- Если игра запущена от администратора, запускайте программу тоже от администратора.
- Жест срабатывает один раз при появлении (если не включено «Повторять»).
- При двух руках приоритет у жестов для двух рук.

## Файлы

- `app.py` — вся программа.
- `requirements.txt` — зависимости.
- `gestures.json` — создаётся автоматически при сохранении.
